# グラデーション作成

色、角度、種類を調整し、CSSの `linear-gradient` / `radial-gradient` を作成する静的Webアプリです。

## 機能
- 線形・円形グラデーション
- 角度調整
- 2〜5色の追加・削除
- カラーコード直接入力
- 色の入れ替え
- ランダム生成
- 8種類のプリセット
- CSSコードのコピー

## 公開方法
GitHubで `gradient-maker` というPublicリポジトリを作り、`index.html`、`style.css`、`script.js`、`README.md` をアップロードします。Settings → Pagesからmainブランチのrootを公開します。
